For each parameter that handles security-relevant data, include its index (0-based) and its likely role.

OUTPUT (strict JSON, no prose)
{
  "function": "{func_name}",
  "is_sink_candidate": true|false,
  "dangerous_params": [
    {"param_index": 0, "role": "brief role description", "reason": "brief reason"}
  ],
  "reason": "brief overall reason"
}

If is_sink_candidate is false, return dangerous_params as an empty list.
